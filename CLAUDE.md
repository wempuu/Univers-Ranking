# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Univers-Ranking is a pop culture mini games website (French UI), hosted on GitHub Pages from the `main` branch root.

## Stack

Plain static HTML/CSS/JS — no build step, no dependencies, no tests yet. Pages `fetch` `data/mangas.json`, so preview through a local HTTP server (opening files via `file://` breaks the character pages). Pushing to `main` redeploys the site.

## Architecture

- `index.html` + `accueil.js` — home page as two full-screen "pages" (`.fp-panel`, `body.fp`): 1) Accueil (hero + the original collage layout (`.c-main` / `.c-side` / `.c-small`), but each frame has its image's exact aspect-ratio so nothing is cropped (update it in style.css if an image changes), overlaps kept off faces, with the user's black-and-white drawings `images/accueil/accueil-{dragon-ball,hunter-x-hunter,one-piece}.jpg` (One Piece big (square drawing of Luffy, Chopper, Zoro, Nami), Hunter × Hunter bottom left, Dragon Ball small, no frame), kept black and white (`.bw`), no vertical text (removed by the user) + a single "Jouer" button to jouer.html + "Scrolle vers le bas pour découvrir les jeux"; the user wants only that one button there), 2) Undercover (`#undercover`, rules + collage of the user's black-and-white drawings `images/accueil/undercover-{naruto,luffy,ichigo}.jpg` (labels are accent-colored boxes with text in the site background grey `--bg`; labels only: Naruto = "Imposteur" (top left), Luffy Gear 5 = "Innocent" (top right, near-square frame (1:1.12) ending above Ichigo's bottom), Ichigo = "Mr. White" centered at the bottom; no vertical text on this collage (the user removed it); no "Perso 01/02"; no frame border on any of the three (Ichigo's was removed; an accent frame on Naruto and a cut-out Luffy on accent were tried and rejected by the user); Naruto and Ichigo are cropped by their frame (object-fit: cover); the Luffy drawing is shown whole in its frame, sized and offset (width 98%, left -9%, top 12%, centered in the free space) so the label never touches him and nothing is cut off), no button, fits the screen; `.fp-scroll` hides its scrollbar), then one more scroll shows the footer (`.fp-panel.fp-footer`, `#bas`): it slides up from the bottom and pushes the page above up by its height (`is-pushed`, `--fp-footer-h`); keep the footer panel last. Wheel, swipe or arrow keys at the bottom/top edge of a page switch pages with a clip-path/slide transition (1.1 s lock against trackpad inertia); each page scrolls inside its own `.fp-scroll`; a fixed bottom-right ▲ button (`.to-top`, created by accueil.js) goes back to page 1 and is shown ONLY on the Undercover page and the footer step (`body.fp-on-undercover`; the user removed it everywhere else); on every page change the collage images appear one by one (staggered by `:nth-of-type`), and fade out when leaving; `#undercover` in the URL opens page 2 directly (jeux.html links there). Add a game page by adding another `.fp-panel` + pagination button. 
- `jouer.html` + `jouer.js` — "Jouer" page (opened by the home "Jouer" button): create a group (pseudo + random 6-char code from `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`, no 0/O/1/I/L) or join one with a code. The pseudo is kept in localStorage (`ur-pseudo`).
- `groupe.html?code=XXXXXX[&hote=1]` + `groupe.js` — group lobby, serverless: PeerJS 1.5.4 (unpkg, public PeerJS broker, WebRTC). The creator (`hote=1`) claims peer id `univers-ranking-<code>` and is authoritative: holds `state = { players, game, rules, status }` and broadcasts it to every guest on each change; guests connect to that id, send `{type:"join", name}` and only render. Only the creator can pick the game and edit rules; max 12 players; if the creator leaves or closes the page the group ends for everyone. Game flow (Undercover) lives in `groupe.js` too: the host draws characters and roles, sends each player only their own character (`{type:"secret"}`), runs turns/timers (`deadline` in host time + `hostNow`, guests correct for clock offset) and keeps roles/votes private until the result.
- `jeux-liste.js` — `GAMES` catalogue of group games (`minPlayers`, rules) with each game's editable `rules` (`number` / `select` / `toggle`, with defaults); the lobby builds its game picker and rule fields from it. Add games here.
- `catalogue.html` + `catalogue.js` — catalogue of universes with a search bar (filters manga cards by title only; the `.grid` uses `auto-fill` so a lone result keeps its normal width); "Mangas" section with one `.card.manga` per series (cover image from `images/catalogue/<slug>`, shown at 2:3; the `--c1`/`--c2` gradient is the fallback behind it).
- `data/mangas.json` — single source of truth: `{ tags: { <tag-slug>: { label, values: [tags in order] } }, mangas: { <manga-slug>: { title, cover, groups: [{ id, label }], characters: [{ name, group, image?, imageSource?, imageCrop?, tags: { <tag-slug>: [values] }, tagRarity?: { <tag-slug>: { <tag>: 2|3 } } }] } } }`. Empty `characters` shows "Liste à venir".

The characters array is kept sorted by group (in `groups` order), and within a group by importance in the story; the list page shows one heading per group, no ranks or vote counts.
