Comment obtenir un jeton ?
  1. Le propriétaire du dépôt doit t'avoir ajouté comme collaborateur (Settings → Collaborators), sauf si c'est ton dépôt.
  2. Sur GitHub : photo de profil → Settings → Developer settings → Personal access tokens.
  3. Propriétaire du dépôt : « Fine-grained tokens » → Generate new token → Repository access : Only select repositories → Univers-Ranking → Permissions : Contents : Read and write.
  4. Collaborateur : « Tokens (classic) » → Generate new token → coche uniquement public_repo.
  5. Copie le jeton et colle-le ici. Il reste uniquement dans ce navigateur.
